### For people who build reading apps

Readers should be able to move their reading history between apps: start dates, rereads, progress and notes. Most of that does not fit in a Goodreads CSV export. We share what Shelvd has built so far. Use any part of it.

**[data-format](https://github.com/getshelvd/data-format)**<br>
The JSON format Shelvd built for library backups: schemas and one example library. Version 1, public domain (CC0).

**[api-documentation](https://github.com/getshelvd/api-documentation)**<br>
Shelvd's API for reading apps. Planned, not open yet.

Questions or ideas? Open an issue in either repository, or write to hello@shelvd.io.
